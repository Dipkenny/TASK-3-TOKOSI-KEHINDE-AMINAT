
# TASK-3-TOKOSI-KEHINDE-AMINAT
# Retail Sales Data Analysis Using SQL
# Project Overview
This project involves analysing a retail sales dataset containing 1,200 records using PostgreSQL.

# Project Objective
To extract meaningful business insights through SQL queries involving data retrieval, filtering, sorting, grouping and aggregation.

# Tools Used
- PostgreSQL
- SQL
- GitHub

# SQL Skills Applied
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- COUNT()
- SUM()
- AVG()
- LIMIT

# Key Business Findings
1. Chairs recorded the highest revenue and quantity sold, while Phones recorded the lowest.
2. Laptops had the highest average order value, while Desks had the lowest.
3. Instagram was the leading recorded referral source, while Online was the most frequently used payment method.

# Deliverables
- SQL queries
- Query execution screenshots
- Business insights report

# Conclusion

The project demonstrates how SQL can be used to analyse retail transactions, identify sales patterns and generate insights that support business decision-making.
